
# Registration Forms

A collection of different registration forms developed for various activities, competitions, and professional purposes. This project includes registration forms for Dance, Drawing, Employee, Kabaddi, Photography, Quiz Competition, Singing Competition, and Student Registration.

Each form is designed with a user-friendly interface and category-specific fields to collect relevant participant information efficiently.

## 📌 Project Overview

The main objective of this project is to create multiple registration forms for different events and purposes. Each registration form has its own design, layout, and input fields according to its requirements.

## 📂 Available Registration Forms

| No. | Registration Form | Purpose |
|---|---|---|
| 1 | 💃 Dance Registration | Registration for dance events and competitions. |
| 2 | 🎨 Drawing Registration | Registration for drawing and art competitions. |
| 3 | 👨‍💼 Employee Registration | Collecting employee personal and professional details. |
| 4 | 🏏 Kabaddi Registration | Registration for Kabaddi players and sports competitions. |
| 5 | 📸 Photography Registration | Registration for photography events and competitions. |
| 6 | 🧠 Quiz Competition Registration | Registration for quiz participants and competitions. |
| 7 | 🎤 Singing Competition Registration | Registration for singing events and musical competitions. |
| 8 | 🎓 Student Registration | Collecting student personal, academic, and contact information. |

## ✨ Features

- Multiple registration forms for different categories.
- Separate form designs for each activity.
